# 📡 Документация по использованию бота AutoParseAlertBot

## 🚀 Быстрый старт за 3 шага

1. **Аккаунт** — «Мой парсинг» → Аккаунт → загрузить файл `.session`
2. **Ключевые слова** — что искать в чатах (можно проверить через «Проверь сообщение»)
3. **Каналы** — добавить @каналы и включить парсинг ✅ в списке

Затем на главном экране нажмите **«Запустить»**. Совпадения приходят в личный чат с ботом.

Чеклист и мастер настройки: `/start` → wizard, если чего-то не хватает.

## 🚀 Основные функции

1. **Отслеживание ключевых слов** — мониторинг новых сообщений в указанных Telegram-группах и каналах в реальном
   времени.
2. **AI-поиск групп/каналов** — два режима поиска (локальный и глобальный) с использованием искусственного интеллекта (
   groq, OpenRouter, G4F).
3. **Актуализация базы данных** — автоматическое обновление информации о типах (группа/канал) и ID площадок
   администратором.
4. **Проверка групп** — ручная проверка конкретных чатов на наличие ключевых слов без подписки.
5. **Экспорт данных** — выгрузка базы в формат Excel (.xlsx) с фильтрацией по категориям и типам чатов.
6. **Многоязычная поддержка** — полный перевод интерфейса на русский и английский языки (Fluent i18n).
7. **Управление аккаунтами** — подключение нескольких аккаунтов через .session файлы для распределения нагрузки.
8. **Массовое добавление групп** — загрузка списков площадок через .txt файлы.
9. **Определение активности** — автоматический расчет статуса группы (active/inactive) по дате последнего сообщения.
10. **Интеллектуальная категоризация** — автоматическое присвоение тематических категорий группам с помощью AI.
11. **Определение языка** — автоматическое определение основного языка контента в группах.

## 🛠 Установка и настройка

### Быстрая установка

1. Скопируйте шаблон конфигурации и заполните обязательные поля:
   ```bash
   cp .env.example .env
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите бота:
   ```bash
   python main.py
   ```

### Переменные окружения

Создайте файл `.env` в корневом каталоге проекта на основе `.env.example`:

```env
BOT_TOKEN=ваш_токен_бота
ID=ваш_api_id
HASH=ваш_api_hash
ADMIN_USER_IDS=123456789
GROQ_API_KEY=ваш_groq_api_key
OPENROUTER_API_KEY=ваш_openrouter_api_key
WEBAPP_URL=https://your-domain.example/
PORT=8000
PROXY_USER=
PROXY_PASSWORD=
PROXY_IP=
PROXY_PORT=
BOT_MODE=polling
WEBHOOK_URL=
WEBHOOK_SECRET=
ENABLE_MOCK_AUTH=false
```

**Бесплатный ключ Groq (для «Инструкция → Задать вопрос» и AI-поиска):**

1. Откройте https://console.groq.com/keys (регистрация Google/GitHub)
2. **Create API Key** → скопируйте ключ (`gsk_...`)
3. В `.env`: `GROQ_API_KEY=gsk_...`
4. Перезапуск: `docker compose up -d --build`

## 💰 Лимиты на скачивание и Telegram Stars

Для снижения нагрузки на сервер на экспорт базы данных наложен лимит:
1. **Бесплатный экспорт** — доступен **1 раз в 24 часа** для любого типа экспорта базы.
2. **Платный экспорт** — повторные скачивания в течение 24 часов стоят **5 Telegram Stars**. При попытке скачать базу во время кулдауна бот предложит списать 5 звезд с вашего баланса или оплатить их напрямую.
3. **Пополнение звезд** — пополнить баланс можно в меню **"⚙️ Настройки"** -> **"💳 Пополнение звезд"** (доступны пакеты на 5, 15, 50 и 100 звезд).

## 🎯 Инструкция по использованию

### 1. Подключение аккаунта

Для парсинга нужен ваш Telegram-аккаунт в виде файла `.session` (Telethon):

1. «Мой парсинг» → **Аккаунт** → подключить / загрузить `.session`
2. Бот проверит сессию и сделает аккаунт активным

**Как получить `.session` (кратко):**

1. На своём ПК установите Telethon: `pip install telethon`
2. Создайте приложение на https://my.telegram.org/apps → получите `api_id` и `api_hash`
3. Скриптом авторизуйтесь по номеру телефона (код из SMS/Telegram) и сохраните сессию в файл, например `my.session`
4. Этот файл отправьте боту в меню аккаунта

Бот **не генерирует** `.session` за вас и не присылает чужие сессии — только принимает ваш файл.

Пример минимального скрипта:

```python
from telethon.sync import TelegramClient

api_id = 12345          # из my.telegram.org
api_hash = "your_hash"
client = TelegramClient("my", api_id, api_hash)
client.start()          # спросит телефон и код
print("Готово: файл my.session")
client.disconnect()
```

### 2. Настройка мониторинга

1. **Ключевые слова:** «Мой парсинг» → Ключевые слова (текст или `.txt`). Есть «Проверь сообщение».
2. **Каналы:** добавьте `@username` / ссылки, включите парсинг ✅ в списке.
3. На главном экране — **«Запустить»**. Совпадения приходят в этот чат с ботом.

### 3. AI-вопросы в инструкции

Раздел «Инструкция» → «Задать вопрос» отвечает через **Groq** (нужен `GROQ_API_KEY` в `.env`).

### 4. AI Поиск

При входе в меню **"✨ Поиск через AI"** вы увидите описание режимов:

- **Локальный поиск:** Использует AI для генерации вариаций запросов и ищет совпадения в Telegram.
- **Глобальный поиск:** Масштабный перебор запросов через все подключенные аккаунты.

### 5. Панель администратора

Доступна по кнопке **"🛡️ Панель администратора"**:

- **🏷️ Присвоить категорию:** Обработка базы через groq или OpenRouter для распределения по темам.
- **🌐 Присвоить язык:** Определение языка (ru/en и др.) для каждой группы.
- **🔄 Актуализация БД:** Проверка доступности групп и обновление их метаданных.

## 🟢 Статусы активности

| Статус          | Описание                                                 |
|:----------------|:---------------------------------------------------------|
| 🟢 **active**   | Сообщения были в течение последних 30 дней               |
| 🔴 **inactive** | Группа заброшена (более 30 дней тишины)                  |
| ⚪ **unknown**   | Не удалось получить данные (приватность или ограничения) |

## 📁 Структура проекта

- `account_manager/` — логика работы с Telegram API (Telethon).
- `ai/` — интеграции с LLM (groq, OpenRouter).
- `database/` — модели Peewee и работа с SQLite.
- `handlers/` — логика команд и диалогов aiogram.
- `locales/` — файлы локализации (.ftl).
- `keyboards/` — сборка кнопок интерфейса.
