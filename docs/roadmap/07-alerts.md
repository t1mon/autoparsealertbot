# Алерты о совпадениях

## Проблема сейчас

Шаблон `keyword_match_alert` (`locales/ru.ftl` / `en.ftl`), сборка в `account_manager/parser.py` → `process_message`:

```
📥 Новое совпадение
Источник: …
Чат: …
Ссылка: …
Ключевое слово: …
Текст сообщения: …
```

**Не хватает:**
- кто написал сообщение (автор): имя, `@username`, user id;
- для каналов — подпись / post author, если есть;
- даты/времени сообщения;
- иногда `Чат: —` (нет username у приватного/linked discussion) — нужно явнее писать тип (канал / группа обсуждений / топик).

Пример реального алерта без автора — непонятно, кому отвечать / кого анализировать:

```
Источник: Horizon VPN — Community
Чат: —
Ссылка: https://t.me/c/…/179418
Ключ: лучший vpn
Текст: но одни из самых лучших)
```

## Целевой формат алерта

```
📥 Новое совпадение

Источник: Horizon VPN — Community (группа обсуждений)
Чат: @horizon_… / id −100…
Автор: Имя Фамилия (@username) · id 123456789
Время: 16.07.2026 15:12 (МСК)
Ссылка: https://t.me/c/…

Ключ: лучший vpn
Почему: … (P2, опционально)

Текст:
…
```

Если автора нет (удалённый аккаунт / канал без подписи): `Автор: — (канал / anonymous)`.
