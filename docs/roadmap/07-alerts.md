# Алерты о совпадениях

## Проблема сейчас

Шаблон `keyword_match_alert` (`locales/ru.ftl` / `en.ftl`), сборка в `account_manager/parser.py` → `process_message`:

```
📥 Новое совпадение
Источник: …
Чат: …
Ссылка: …
Ключевое слово: …
Текст сообщения: …
```

**Не хватает:**
- кто написал сообщение (автор): имя, `@username`, user id;
- для каналов — подпись / post author, если есть;
- даты/времени сообщения;
- иногда `Чат: —` (нет username у приватного/linked discussion) — нужно явнее писать тип (канал / группа обсуждений / топик).

Пример реального алерта без автора — непонятно, кому отвечать / кого анализировать:

```
Источник: Horizon VPN — Community
Чат: —
Ссылка: https://t.me/c/…/179418
Ключ: лучший vpn
Текст: но одни из самых лучших)
```

## Целевой формат алерта

По умолчанию — полный шаблон (`alert_template=full`). В настройках (`menu:alert_template`) можно выбрать:

| Пресет | Содержимое |
|--------|------------|
| `full` | источник, чат, автор, время, ссылка, ключ, почему, текст |
| `compact` | ключ + источник, автор, время, ссылка, почему, текст |
| `minimal` | ключ, почему, ссылка, текст |

```
📥 Новое совпадение

Источник: Horizon VPN — Community (группа обсуждений)
Чат: @horizon_… / id −100…
Автор: Имя Фамилия (@username) · id 123456789
Время: 16.07.2026 15:12 (МСК)
Ссылка: https://t.me/c/…

Ключ: лучший vpn
Почему: слова: лучший, vpn · режим «умный»

Текст:
…
```

Если автора нет (удалённый аккаунт / канал без подписи): `Автор: — (канал / anonymous)`.

## Маршрутизация доставки (P0–P1)

Настройки → **Куда слать алерты** (`menu:alert_destination`):

| Режим | Поля `User` |
|-------|-------------|
| Только личка | `alert_to_dm=True`, `alert_to_group=False` |
| Только группа | `alert_to_dm=False`, `alert_to_group=True` |
| Оба | оба флага `True` |

Привязка группы: команда `/bind_alerts ТОКЕН` в supergroup/топике (токен из меню, TTL ~15 мин, только admin, один чат — один владелец).  
Сохраняются `alert_chat_id` и `alert_thread_id` (топик форума).

Единая доставка: `core/alert_delivery.py` → `deliver_alert()` (алерты и дайджест).
