## Целевой UX

Подменю **🔑 Ключевые слова**:

| Действие | Как |
|----------|-----|
| Добавить текстом | Несколько строк / через запятую |
| Добавить файлом | `.txt` (одна фраза на строку), опционально `.xlsx` |
| Смотреть списком | Inline-список с пагинацией, удаление `✕` у пункта |
| Скачать файлом | `.txt` и/или `.xlsx` |
| Очистить всё | С подтверждением |
| Тест | Ввести фразу → какие ключи сработали (связь с матчингом) |
