## Целевой UX

Подменю **📢 Каналы**:

| Действие | Как |
|----------|-----|
| Добавить текстом | `@user` / `t.me/...` / id, несколько строк |
| Добавить файлом | `.txt` |
| Список в боте | Пагинация; у каждого: ✅ парсить / ⏸ выкл, удалить |
| Скачать файлом | `.txt` / `.xlsx` |
| Массово | Включить все / выключить все |
| Импорт из аккаунта (P2) | Подтянуть диалоги Telethon и выбрать галочками |

Статус на главном: `8 включено / 19 в списке` (+ опционально «слушаю N»).
