# UX и структура меню

## Проблема сейчас

- Главное меню смешивает **запуск парсинга**, разовую проверку группы, AI-поиск, выгрузку базы и настройки.
- Неочевидно, с чего начать новому пользователю («куда тыкать, чтобы запустить проект»).
- Нет единого экрана готовности: аккаунт / ключи / каналы / статус.
- Настройки — «свалка» кнопок без группировки по сущностям (ключи · каналы · аккаунт).

## Целевая модель

### Главный экран (после /start)

Текст-статус, например:

```
📡 Парсинг: ▶ работает / ⏹ остановлен
👤 Аккаунт: +7… (Имя) / не подключён
🔑 Ключей: 12
📢 Каналов: 8 включено / 19 всего
```

Кнопки:

1. **▶ Запустить** / **⏹ Остановить** (главный CTA)
2. **Мой парсинг** → чеклист + сущности
3. **Найти / база** (AI, выгрузка) — вторичный блок
4. **Помощь**
5. Админка (если admin)

### Экран «Мой парсинг»

- [ ] Чеклист: ☐ Аккаунт · ☐ Ключи · ☐ Каналы
- [ ] Кнопки: Аккаунт · Ключевые слова · Каналы для парсинга
- [ ] «Запустить» активна только если все ☐ закрыты (или с явным предупреждением)

### Настройки — разнести

Вместо плоского списка:

- Ключевые слова → подменю CRUD
- Каналы → подменю CRUD + toggle
- Аккаунт → статус / сменить / подключить
- Язык, Stars, transfer — «Прочее»
